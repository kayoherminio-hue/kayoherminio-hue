## 🚀 Current Project

<div align="center">
  <img src="https://img.shields.io/badge/PROJECT-TJR%202026-2563EB?style=for-the-badge" />
  <h3>🤖 Autonomous Line-Following Robot</h3>
</div>

I'm currently working on the development of an autonomous robot for the **Torneio Juvenil de Robótica (TJR)**.

The project involves building and improving a robot capable of following a track, detecting curves, interpreting sensor readings, and navigating different challenges.

**Main areas of development:**

- ⚙️ Robot assembly and hardware integration
- 🔌 Sensor reading and calibration
- 🐍 Python programming with EV3 and ev3dev2
- 🎯 Control algorithms for line following
- 🔄 PID control and parameter tuning
- 🧪 Testing, debugging, and performance optimization

This project is an opportunity to apply concepts from programming, electronics, control systems, and mechanical engineering to a real competition robot.
